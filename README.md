# Сайт ООО «Технодор»

Адаптивный одностраничный сайт на HTML, CSS и JavaScript. Не требует сборки и платных библиотек.

## Просмотр на компьютере
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для корректной работы всех внешних изображений нужен интернет. Локальные фотографии из папки `images` имеют приоритет.

## Как заменить изображения на свои
Поместите фотографии в папку `images` и используйте следующие имена:
- `hero.jpg` — широкое фото для первого экрана;
- `earthworks.jpg` — земляные работы;
- `demolition.jpg` — демонтаж;
- `waste.jpg` — вывоз отходов;
- `statement.jpg` — дополнительное широкое фото для тёмного блока.

Форматы JPG или WebP. Для `hero.jpg` и `statement.jpg` лучше широкие фотографии. Если файл не добавлен, используются встроенные фоновые изображения (где предусмотрен резервный источник) либо цветные заглушки. Чтобы портфолио показывало собственные фотографии, откройте `styles.css` и замените фоновые градиенты `.project-one`, `.project-two`, `.project-three`, например:
`background-image: url('images/project-01.jpg');`
Затем положите соответствующие фотографии в папку `images`.

## Как опубликовать бесплатно на GitHub Pages
1. Создайте аккаунт на https://github.com/.
2. Создайте новый публичный репозиторий, например `tehnodor-site`.
3. Загрузите в репозиторий `index.html`, `styles.css`, `script.js` и папку `images`.
4. В репозитории откройте **Settings → Pages**.
5. В разделе Build and deployment выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем нажмите **Save**.
6. Подождите завершения публикации. Адрес появится в этом же разделе Pages и будет иметь вид `https://ВАШ-ЛОГИН.github.io/tehnodor-site/`.

Альтернативно можно использовать бесплатный статический хостинг Netlify: https://www.netlify.com/ — загрузите папку сайта через доступный в аккаунте способ публикации.

## Важные сведения
- Телефон и электронная почта внесены по данным заказчика.
- Форма не отправляет данные на сервер. После заполнения она формирует письмо через `mailto:` и открывает почтовое приложение пользователя. Отправка происходит вручную. Для надёжного сбора заявок понадобится подключить серверную форму или внешний сервис форм.
- На сайте намеренно не указаны неподтверждённые цены, адрес офиса, лицензии, сроки, гарантии, реквизиты и количество выполненных проектов.
- Перед публикацией замените заглушки портфолио реальными фотографиями и проверьте все формулировки, согласия на обработку персональных данных и юридические сведения.
- Шрифт подключается с Google Fonts; при отсутствии доступа к нему используются системные шрифты.
